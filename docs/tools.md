## Что подходит этой репе

Для визуального просмотра связей первый кандидат — **Agent Flow**. Он читает Codex rollout JSONL, показывает интерактивный граф, инструменты и таймлайн. Это отдельный наблюдатель, а не навык, который нужно загружать в каждый запрос. [Исходный проект](https://github.com/patoles/agent-flow).

Запуск на компьютере, где лежат сессии Codex:

```bash
AGENT_FLOW_RUNTIME=codex AGENT_FLOW_TELEMETRY=false npx agent-flow-app
```

Либо установи [расширение VS Code](https://marketplace.visualstudio.com/items?itemName=simon-p.agent-flow) и выбери `agentVisualizer.runtime = "codex"`. Указанные команды подготовлены по документации; приложение в этой среде не запускалось. [Настройки и запуск](https://github.com/patoles/agent-flow#runtime-selection).

**Agent Monitor** ближе к задаче «дерево всех агентов + токены». Он показывает отношения родитель/подагент, трассы и оценку стоимости; проект значительно меньше по популярности. [Документация автора](https://github.com/donvito/agent-monitor).

**oh-my-codex** — более популярный кандидат для самой координации. Основной поддерживаемый путь — macOS/Linux и Codex CLI. Плагин требует установленного CLI `omx` и scoped setup; один marketplace-пакет его не заменяет. HUD показывает участников и состояние команды; это не равнозначно интерактивному графу связей. [README](https://github.com/Yeachan-Heo/oh-my-codex).

Пример отдельной установки в выбранном рабочем проекте:

```bash
npm install -g oh-my-codex
omx setup --scope project --merge-agents
omx doctor
omx hud --watch
```

Setup меняет инструкции и настройки выбранного проекта. В основе этой репы уже есть нативные роли, поэтому OMX оставлен отдельным вариантом. Не включай одновременно несколько слоёв оркестрации без сравнения их поведения.

**Superpowers** доступен в каталоге плагинов Codex; ищи `superpowers` через `/plugins`. Он полезен как готовая методология, но дополнительные планы, проверки и подагенты не гарантируют меньший расход. Для собственного компактного набора он пока не является обязательной зависимостью. [Установка и workflow](https://github.com/obra/superpowers#codex-cli).

**Langfuse** стоит выбирать для собственных приложений и агентов с инструментированной трассировкой. Есть [интеграция OpenAI Agents SDK](https://langfuse.com/integrations/frameworks/openai-agents). Это не подтверждение автоматического подключения ко всем локальным сессиям Codex.

## Что будет видно

Наблюдатели показывают события, которые реально выдаёт runtime: сообщения, вызовы инструментов, результаты, статусы, доступные summaries и токены. Это не полный доступ к скрытым внутренним рассуждениям. Связи видны только там, где источник сохраняет соответствующие события; независимые сессии без зарегистрированной связи нельзя достоверно соединить.

Для браузерного наблюдателя, запущенного в контейнере, сессии с другого компьютера сами не появятся. Запускай его рядом с источником логов или настраивай поддерживаемое подключение. Каталог [catalog/tools.json](../catalog/tools.json) хранит статус рекомендаций; ни один внешний инструмент здесь не установлен.
