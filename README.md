# Codex Agents

Базовая репа для настройки Codex: компактные навыки, роли подагентов, промпты и каталог внешних инструментов. Приоритет — достаточный контекст, проверяемый результат и минимум повторной работы.

## Начать

Открой эту папку как проект Codex. В CLI:

```bash
cd codex-agents
codex
```

Настройки `.codex/config.toml` применяются для доверенного проекта. Модель и уровень рассуждений наследуются из твоих настроек. Роли используют штатные подагенты Codex; задан предел в два одновременно открытых подагента помимо основного. Это ограничение, а не обязательный состав команды. [Официальная документация](https://learn.chatgpt.com/docs/agent-configuration/subagents).

Примеры запросов:

```text
$context-scout Найди код, который отвечает за авторизацию, и команды его проверки.
$debug-issue Исправь падение теста: <команда и ошибка>.
$review-changes Проверь текущие незакоммиченные изменения.
$coordinate-work Раздели эту задачу между подагентами с отдельными владельцами файлов.
```

## Навыки

| Навык | Когда полезен |
| --- | --- |
| `context-scout` | Найти нужные файлы и контракты без загрузки всей репы |
| `debug-issue` | Проверить причину сбоя и устранить её |
| `verify-change` | Подобрать достаточную проверку результата |
| `review-changes` | Найти конкретные дефекты в изменениях |
| `coordinate-work` | Раздать независимые задачи с границами владения |
| `session-handoff` | Передать цель, решения, проверки и следующий шаг в другую сессию; входит в плагин |

Это собственные короткие инструкции для стартового набора. Они не являются копиями навыков Superpowers или OMX и пока не проходили сравнительный модельный бенчмарк. Выигрыш в токенах и качестве нужно проверять на своих задачах.

Codex сначала видит метаданные навыка и загружает полный текст по необходимости. Поэтому описания короткие, а задачи навыков разделены. [Как Codex загружает навыки](https://learn.chatgpt.com/docs/build-skills).

## Промпты и плагин

В `prompts/` находятся обычные Markdown-шаблоны: замени `{{поля}}` и отправь текст в Codex либо попроси прочитать конкретный файл. Эта папка сама по себе не регистрирует slash-команды.

Для локального `session-tools` подготовлены marketplace и разрешающее включение в проектном конфиге. Сам плагин в текущем клиенте ещё не установлен. В CLI зарегистрируй эту репу и установи пакет из её корня:

```bash
codex plugin marketplace add .
codex plugin add session-tools@codex-agents
codex plugin list --marketplace codex-agents --json
```

После установки попроси: «Подготовь краткую передачу этой задачи в новую сессию». Плагин не содержит MCP, хуков и внешних сервисов. Для поддерживающего repo marketplace desktop-клиента доступность проверь после обновления каталога или перезапуска. [Устройство локального marketplace](https://developers.openai.com/plugins/build/plugins).

## Перенести в рабочий проект

Скопируй нужные папки из `.agents/skills/` в `<проект>/.agents/skills/`, а нужные роли — в `<проект>/.codex/agents/`. Возьми [шаблон AGENTS.md](templates/project-AGENTS.md) и укажи реальные команды своего проекта. Совмести нужные настройки с существующим конфигом.

Для плагина перенеси `plugins/session-tools/` и соответствующую запись marketplace. Путь `source.path` считается от корня репозитория. Внешние инструменты из каталога здесь не установлены и не включены.

## Проверки

Нужны Python 3.11+ и Git. Дополнительных Python-зависимостей нет.

```bash
python3 scripts/check.py
python3 -m unittest discover -s tests
```

Проверки валидируют локальные форматы, пути и расчёт usage. Они не доказывают улучшение поведения модели. Для реальных сравнений используй [методику оценки](evals/README.md).
